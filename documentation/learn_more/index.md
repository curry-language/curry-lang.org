=======================

<section>      
:::md:max-w-3xl

Here are a few links to further resources related to Curry.

[Wikipedia entry for Curry](http://en.wikipedia.org/wiki/Curry_(programming_language))

[A short review on functional logic programming](http://doi.acm.org/10.1145/1721654.1721675)
(appreared in CACM)

[A longer survey on functional logic programming and Curry](http://dx.doi.org/10.1007/978-3-642-37651-1_6)

[Functional Logic Design Patterns](http://web.cecs.pdx.edu/~antoy/flp/patterns/)
A catalog of design patterns related to functional logic programming.

[Example programs (executable in a web browser)](https://smap.curry-lang.org/smap.cgi?browser/programs?lang=curry)
available in
[Smap](https://smap.curry-lang.org/) (an interactive web-based source code editor)

[Example programs](http://www.informatik.uni-kiel.de/~curry/examples/)
A collection of (small) Curry programs that are distributed with
[PAKCS](https://www.curry-lang.org/pakcs/)

[Base libraries](https://cpm.curry-lang.org/pkgs/base.html)
A collection of libraries for Curry that are contained in Curry distributions like
[PAKCS](https://www.curry-lang.org/pakcs/),
[KiCS2](https://www.curry-lang.org/kics2/), or
[Curry2Go](https://www.curry-lang.org/curry2go/)

[Packages](https://cpm.curry-lang.org/)
A collection of packages available by the
[Curry Package Manager (CPM)](https://www.curry-lang.org/tools/cpm)

[FlatCurry](https://cpm.curry-lang.org/pkgs/flatcurry.html)
An intermediate representation for Curry programs which is used in various
meta-programming tools for Curry, like compilers, program analyzers, verification tools etc.
