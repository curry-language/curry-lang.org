Report on Curry
===============

:::
</section>
<section>      
:::md:max-w-3xl

Since the design and implementation of Curry is under development, the
language definition contained in the report should be considered as
preliminary in various aspects. Nevertheless, the report is the main
reference on Curry so that implementations of Curry should refer to
this report to explain restrictions or differences.

If you are interested in a general introduction to programming in Curry,
please look into the
[tutorial on Curry](/documentation/tutorial/).

:::
