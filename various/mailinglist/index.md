Curry Mailing List
==================

:::
</section>
<section>      
:::md:max-w-3xl

The Curry mailing list is the forum to dicuss all topics related to
the design, development, and application of the functional logic
language Curry. This list is maintained by
[Michael Hanus](https://www.informatik.uni-kiel.de/~mh).
**Requests should be directly addressed to the list maintainer**.

Please send contributions to this list to `curry_AT_lists.rwth-aachen.de`.
Note that only subscribed members of the mailing list can post contributions to this list.

You can also look at the current list of
[subscribers](http://www-ps.informatik.uni-kiel.de/~mh/currylist/members.cgi).

If you are interested in previous messages distributed via this mailing list,
you can look into the Curry mailing list
[archive](http://www.informatik.uni-kiel.de/~curry/listarchive/).

:::
