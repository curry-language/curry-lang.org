--- title: Curr(y)gle API Search date: 1970-01-04 # used for the page order (chronologically) learn_more: https://cpm.curry-lang.org/currygle/ --- Curr(y)gle is a Curry API search engine which allows you to search the Curry libraries indexed by CPM. You can search by names of either operations, data types, and modules. It was designed following the example set by Haskell's search engine Hoogle.
