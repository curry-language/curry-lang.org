--- title: Type Inference date: 1970-01-02 # used for the page order (chronologically) learn_more: https://www-ps.informatik.uni-kiel.de/currywiki/ --- Type annotations of functions need not be written by the programmer, they are automatically inferred by the compiler using a type inference algorithm. Nevertheless, it is a good style to write down the types of functions in order to provide at least a minimal documentation of the intended use of functions.
